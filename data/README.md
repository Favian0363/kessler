# Orbit data

Data files are downloaded, not committed. Record the download date of every
dataset you report results on.

- **Quick start / testing:** CelesTrak general perturbations (GP) data, e.g. the
  "active satellites" group, available in TLE format from https://celestrak.org
- **Full public catalog (debris and rocket bodies included):** a free
  Space-Track account at https://www.space-track.org (requires accepting their
  user agreement).
